# 手机 App 导航整理方案

更新：2026-09-06。对应本次桌面侧栏精简，同步用于 Android App 和窄屏 Web。

## 1. 手机端布局

默认进入聊天，点击左上角菜单打开抽屉。抽屉宽度为屏幕宽度的 88%，最大 320px；页面右侧保留遮罩区域，点击即可关闭。

```text
┌──────────────────────────┐
│ 阿安的工作台             │
├──────────────────────────┤
│ Super Chat     Pulse     │
│ Todo           网盘      │
├──────────────────────────┤
│ 常用 Agent             ▾ │
│ 研究助手                 │
│ ……                       │
├──────────────────────────┤
│ 最近会话               ▾ │
│ [搜索会话              ] │
│ 导航栏改版方案           │
│ 本周工作计划             │
│ ……                       │
│ 滑到底部自动加载更多     │
├──────────────────────────┤
│ 设置与管理               │
│ [当前账号           ▾] ⇄ │
└──────────────────────────┘
```

| 区域 | 手机端行为 |
| --- | --- |
| 主导航 | 4 个入口排成两列，始终可见；点击后关闭抽屉。 |
| 常用 Agent | 单行显示图标和名称，可折叠；没有有效固定项时隐藏整区。禁用项仍不可点击。 |
| 最近会话 | 每次请求 20 条，在独立滚动区域显示；接近底部时按游标加载更早会话，直至末页。较早的当前会话仍单独保留可见。 |
| 搜索 | 在服务端按标题搜索当前账号的历史会话，搜索结果同样分批加载；不搜索消息正文。 |
| 加载状态 | 移除“查看全部”；加载时显示轻量提示，失败保留列表并提供重试。重复滚动不会重复请求。 |
| 设置和账号 | 固定在抽屉底部。切换账号时清空搜索和分页状态，丢弃旧账号未完成的请求结果。 |
| 模型选择 | 放在“设置与管理”页面的模型选择区，宽度随屏幕收缩；聊天输入区和顶部不再展示模型选择。 |

## 2. 设置与管理

从抽屉底部进入独立页面，手机上使用单列入口，不再在抽屉中展开长菜单。

- **模型选择**：选择当前聊天使用的模型，保留“默认模型”选项。
- **应用连接**：Connect。
- **助手配置**：Role、Memory、Tool、Agents。
- **开发与调试**：Trace、Eval、管理员配置。

进入管理子页后，顶部显示“返回设置与管理”；抽屉中的设置入口保持高亮。管理员配置仍打开原有独立页面，沿用原有权限。

Android 返回键按顺序处理现有弹窗、侧栏抽屉和页面层级：管理子页回设置首页，设置首页沿用现有返回聊天行为，聊天页返回后台。

## 3. 触屏与小屏细节

- 主导航、会话行、Agent 快捷入口及底部控件至少 44px 高。
- 手机会话删除按钮常显，避免依赖鼠标悬停。
- 账号、搜索和模型选择使用 16px 字号。
- 抽屉顶部和底部保留系统安全区；管理页面可纵向滚动。
- 管理页隐藏聊天专属的新话题和角色选择控件。
- 保留现有键盘避让机制，输入区高度变化继续触发聊天历史浮层位置更新。

## 4. 与桌面端的对应关系

| 项目 | 桌面端 | 手机端 |
| --- | --- | --- |
| 导航容器 | 左侧固定侧栏 | 默认关闭的抽屉 |
| 4 个主入口 | 单列 | 两列 |
| 管理页面 | 双列入口 | 单列入口 |
| 会话与常用 Agent | 紧凑单行 | 更大的触摸区域 |
| 模型选择 | 设置与管理 | 设置与管理 |

## 5. 实现与验证

共享页面为 `web/index.html`，响应式样式为 `web/static/css/style.css`；720px 及以下应用手机布局。Android 返回键逻辑位于 `mobile/android-bridge.js`。

自动化单元测试覆盖模型选择归属管理页、聊天区域不重复显示、导航分组、高亮与返回入口、手机抽屉关闭、Android 返回层级、会话游标分页、底部自动续载、历史搜索、空结果、重复请求、失败重试、账号切换重置、加载中删除、空固定项和禁用 Agent。

Android 网页资源通过 `npm run build:android:web` 构建；发布这些共享网页改动时同步发布增量 OTA，无需新 APK。网页预览不能替代真机键盘、系统安全区和原生返回键的最终验收。
