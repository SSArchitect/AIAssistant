# 继续一键生成：配置恢复与草案修正

2026-09-18 线上“继续一键生成”请求返回 202 后，在约 30 毫秒内失败，尚未提交媒体任务。实际模型复测还发现了草案修正与结构约束问题。

## Agent 独立重启后的配置恢复

模型配置保存在 Gateway 数据库，Agent 内存中的运行时配置会在重启时丢失。创作此前直接调用 Agent，遗漏了聊天已有的同步步骤；因此独立重启后会退回缺少密钥的初始模型配置。该初始化 ValueError 又被误报成了方案格式错误。

CreationHandler 对真实 Agent 客户端统一包装：规划、流式规划、自动审阅和每次媒体节点调用前，都重新同步持久化配置。配置同步使用当前任务的取消信号，最长等待 10 秒；失败时不提交后续模型或生成请求，已确认内容保留。

模型初始化配置异常单独返回 provider_config_missing；同步失败、模型配置问题与方案格式错误不再混为一谈。流式规划和一键生成使用相同的安全错误映射，未知上游正文不会暴露到用户界面。

## 修正草案时保留其余修改

真实规划实测暴露了另一个问题：第一份 revision 草案因一个 purpose 字段错误未通过校验，第二份响应只修正了该字段。旧实现将第二份修正直接应用于已保存画布，丢掉第一份草案的其他修改，导致用户已回答的交付方式和画幅仍显示为未解决问题。

现在按稳定节点 ID 将第二份修正合并到待提交草案，再统一校验完整结果。null 仍表示不修改，节点中的数组字段仍为完整替换。未通过的草案不会提前写入项目；已确认节点保护和跨账号资产检查始终对照原始画布执行。

## 精确约束与逐节点错误

局部修改的动态 schema 原先只复制字段类型，丢掉了 FieldInfo 中的时长、数量、长度限制与说明。现在保留所有字段约束，仅将非 ID 字段改为可省略；ID 仍必填。

视频自身约束在节点层校验，能够同时报告多个错误节点的 ID、位置和需要修正的字段：视频 count 必须为 1，asset_id 和 character_style 必须为空，storyboard 必须完整。画风应写入 storyboard.style，身份图用 references。错误不再仅指向整份 plan，并泛称“视频不合法”；模型修正收到准确字段要求，且仍需通过完整依赖和审批保护校验。

完整图校验会汇总每个视频的执行约束错误，并同时报告其编译后的真实字符数与本节点独立的 Picture 编号。渲染函数只用于诊断，不绕过执行前校验，也不截断对白或用户内容。提示词明确每段独立编号、执行文本预留结构标签空间；自动修正仅修改错误字段，保留详细中文审阅稿。编译长度错误也能正确映射为可读的长度限制提示。

对于供应商响应中已复现的多余对象结束括号和错放到节点层的 storyboard 专属字段，增加有限、保值的格式归一；只删除字符串外最多三个确实无法匹配的对象结束括号，只搬回具有唯一合法位置的字段，存在冲突、未知字段或截断内容时仍拒绝。归一后继续完整 schema、资产归属和锁定节点检查。

## 节点级执行稿压缩工具

模型即使收到总字数限制仍可能返回过长的英文执行稿。新增创作 Agent 内部 `creation_compaction` 工具：只处理未锁定、确实超限的视频，将可编辑叙述拆成有明确字符预算的字符串字段，优先用紧凑中文表达。详细审阅稿、时间线、参考定义与保留分析、参考规则、连续性锁和执行约束不变；对白、引号原文、主体/图片标记的原文和次数必须一致。

预算由实际编译后的固定开销计算，保留 100 字符余量；每节点最多三次有限调用，失败不提交生成，不以截断文字代替修正。候选重新经过完整编译和画布校验后才返回，模型用量归入本轮统计。没有新增模型服务或媒体生成授权入口。

## 验证和发布

- 配置回归测试覆盖四类 Agent 操作、独立重启、同步失败不调用模型、停止时取消同步，以及恢复后继续生成并保留用户审批。
- Python 回归测试覆盖配置错误分类、局部修正保留其他草案修改、仍拒绝覆盖锁定节点和引用陌生资产。
- 结构回归测试覆盖局部修改 schema 的必填 ID、时长/数量/长度约束和字段说明，以及多个视频节点所有错误字段的定位。
- 多视频回归覆盖同时存在的参考图编号错误和编译长度超限，确认一次反馈全部节点；原视频编译与对白保护测试继续通过。
- 格式归一回归覆盖原值保留、冲突/未知字段/截断拒绝和资产归属检查。节点压缩回归覆盖成功路径、时间/规则/对白保留、原画布不变、锁定节点跳过，以及拒绝更改对白并在有限次数后结束。
- 本次仅修改后端、测试和文档，不改变 Web/Android 资源，不需要 OTA。
- 生产更新须先备份数据库、配置和 Gateway 二进制；确认无正在执行的任务后重启 Agent/Gateway，并校验运行时模型配置与持久化配置一致。
