## 自动重试行为

审阅的临时服务故障、超时、回复格式及部分可恢复的依据格式错误最多重试两次，间隔 2 秒、4 秒。每次使用原候选、原需求和审批上下文，进程中显示 `review_retry`，不重跑媒体。每次重试前重新检查自动请求状态和项目版本；等待期停止立即生效，版本变化拒绝使用过时输入。

Gateway 保留 Agent 的结构化错误码，502/503/504 的非结构化网关失败可作为临时故障；未知语义错误、鉴权、额度和方案约束不盲目重试。审阅中的验证与选图权限检查维持原逻辑。记录重试进度本身会递增项目版本，代码跟踪自己的版本更新，同时拒绝并发修改。

规划的单次墙钟超时使用已有分段协议，保留已完成分段。正常流与超时流均关闭连接；用户取消不会触发重试。原有整轮调用预算与 900 秒绝对上限保持有效。HTTP 200 之后 SSE 里的明确 `InternalServerError` 等临时代码现在可重试，错误正文不进入进程消息。
