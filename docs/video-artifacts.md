# 视频产物与播放契约

生成的视频通过 `ChatResponse.artifacts` 交付，播放器不依赖模型正文的 Markdown 格式。

- 只有成功的 `generate_video` 工具结果可以生成视频产物；地址取自工具保存的本地 MP4。
- 产物类型为 `video`，包含稳定的 `item_id`、`url`、`mime_type`、标题，以及工具返回的任务 ID、视频参数和 seed。
- 编排器直接收集工具产物；Gateway 的现有 artifacts 字段负责响应、消息持久化、历史查询和任务恢复，无需数据库迁移。
- 实时回复完成和历史消息使用相同的视频产物组件，支持播放、打开和下载。Android 相对地址通过 API_BASE 解析。
- 存在有效视频产物时，正文只渲染视频链接，不再从正文创建视频播放器，避免重复。图片仍正常渲染。
- 没有结构化产物的旧消息继续兼容 Markdown 视频链接，包括加粗、表情和说明文字。保留服务端 Markdown 链接恢复，兼容旧客户端和纯文本消费方。
- 不从模型编造的 URL 创建结构化产物，不改写既有聊天记录。

验证覆盖：成功/失败工具结果、无链接的模型回复、产物去重、持久化与账号隔离、历史消息、流式完成、旧消息、Android 域名及发布包内真实渲染器。
